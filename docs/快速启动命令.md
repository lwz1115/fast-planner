# 快速启动命令

---

## 一、RViz 可视化

```bash
ros2 launch plan_manage rviz.launch.py
```

---

## 二、规划启动

### 动力学规划（Kinodynamic）

```bash
ros2 launch plan_manage kino_replan.launch.py
```

### 拓扑规划（Topological）

```bash
ros2 launch plan_manage topo_replan.launch.py
```

---

## 三、FastAPI 服务

```bash
cd ~/colcon_ws/fastapi_planner
python3 -m main
```

启动后访问：`http://<设备IP>:8000/docs`

---

## 四、测试 FastAPI 端点

```bash
cd ~/colcon_ws/fastapi_planner
```

### 算法选择测试

```bash
PYTHONPATH=/root/colcon_ws python3 -m pytest test_algorithm_selection.py -v
```

### 深度端点测试

```bash
python3 test_depth_endpoints.py
```

### 错误处理测试

```bash
python3 test_error_handling.py
```

### 运行所有测试

```bash
PYTHONPATH=/root/colcon_ws python3 run_algorithm_tests.py
```
