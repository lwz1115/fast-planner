## 系统要求

在开始之前，请确保您的系统满足以下要求：

- **操作系统**: Ubuntu 20.04 或更高版本
- **ROS**: ROS Noetic（或 Melodic）
- **Python**: Python 3.8 或更高版本
- **Fast-Planner**: 已安装并配置的 Fast-Planner ROS 包

## 快速安装

### 1. 安装 Python 依赖

```bash
cd fastapi_planner
pip3 install -r requirements.txt
```

### 2. 配置环境变量

```bash
# 复制环境变量模板
cp .env.example .env

# 编辑 .env 文件（可选，使用默认值即可开始）
nano .env
```

基本配置示例：
```bash
ROS_MASTER_URI=http://localhost:11311
FASTAPI_PORT=8000
LOG_LEVEL=info
```

### 3. 检查配置文件

查看 `config.yaml` 确保配置符合您的环境：

```yaml
ros:
  master_uri: "http://localhost:11311"
  topics:
    odometry: "/state_ukf/odom"
    goal: "/move_base_simple/goal"
    trajectory: "/planning/bspline"

planning:
  default_max_velocity: 3.0
  default_max_acceleration: 2.0
  planning_timeout: 5.0

map:
  size_x: 40.0
  size_y: 20.0
  size_z: 5.0
```

## 启动服务

### 步骤 1: 启动 ROS Master

在第一个终端中：

```bash
roscore
```

### 步骤 2: 启动 Fast-Planner

在第二个终端中：

```bash
# 启动 Fast-Planner（根据您的算法选择）
roslaunch plan_manage kino_replan.launch
```

### 步骤 3: 启动 FastAPI 服务

在第三个终端中：

```bash
cd fastapi_planner
python3 -m fastapi_planner.main
```

您应该看到类似以下的输出：

```

2025-11-11 10:30:45 - INFO - ROS Bridge connected successfully
2025-11-11 10:30:45 - INFO - Service listening on 0.0.0.0:8000
```

## 第一个规划请求

### 使用 cURL

```bash
curl -X POST "http://localhost:8000/plan" \
  -H "Content-Type: application/json" \
  -d '{
    "start": {"x": 0.0, "y": 0.0, "z": 1.0},
    "goal": {"x": 10.0, "y": 5.0, "z": 1.5},
    "max_velocity": 3.0,
    "max_acceleration": 2.0,
    "algorithm": "kinodynamic"
  }'
```

### 使用 Python

创建文件 `test_planning.py`：

```python
import requests
import json

# 规划请求
response = requests.post(
    "http://localhost:8000/plan",
    json={
        "start": {"x": 0.0, "y": 0.0, "z": 1.0},
        "goal": {"x": 10.0, "y": 5.0, "z": 1.5},
        "max_velocity": 3.0,
        "max_acceleration": 2.0,
        "algorithm": "kinodynamic"
    }
)

# 打印结果
if response.status_code == 200:
    data = response.json()
    if data["success"]:
        print(f"✅ 规划成功！")
        print(f"   航点数量: {data['trajectory']['num_waypoints']}")
        print(f"   轨迹时长: {data['trajectory']['total_duration']:.2f}秒")
        print(f"   规划耗时: {data['planning_time_ms']:.2f}毫秒")
    else:
        print(f"❌ 规划失败: {data['error']['message']}")
else:
    error = response.json()
    print(f"❌ 错误 {response.status_code}: {error['message']}")
    print(f"   详情: {error.get('details', 'N/A')}")
```

运行测试：

```bash
python3 test_planning.py
```

## 常见问题

### 问题 1: "ROS Master not found"

**症状**: 服务启动失败，提示无法连接到 ROS Master

**解决方案**:
```bash
# 检查 ROS Master 是否运行
rostopic list

# 如果没有运行，启动 roscore
roscore

# 检查 ROS_MASTER_URI 环境变量
echo $ROS_MASTER_URI
```

### 问题 2: "Fast-Planner node not responding"

**症状**: 健康检查显示 `"fast_planner_available": false`

**解决方案**:
```bash
# 检查 Fast-Planner 节点是否运行
rosnode list | grep fast_planner

# 如果没有运行，启动 Fast-Planner
roslaunch plan_manage kino_replan.launch

# 检查话题是否存在
rostopic list | grep planning
```

### 问题 3: "Odometry unavailable"

**症状**: 规划请求返回 503 错误，提示里程计不可用

**解决方案**:
```bash
# 检查里程计话题是否发布
rostopic echo /state_ukf/odom -n 1

# 如果话题不存在，检查配置文件中的话题名称
# 或者在规划请求中不使用 use_current_odom
```

### 问题 4: "Position out of bounds"

**症状**: 规划请求返回 400 错误，提示位置超出边界

**解决方案**:
- 检查 `config.yaml` 中的地图尺寸配置
- 确保起点和目标点在地图范围内
- 地图边界: X=[0, 40], Y=[0, 20], Z=[0, 5]（默认配置）

### 问题 5: "Planning timeout"

**症状**: 规划请求返回 504 错误，提示超时

**解决方案**:
- 增加 `config.yaml` 中的 `planning_timeout` 值
- 检查 Fast-Planner 是否过载
- 验证目标点是否可达
- 简化规划场景（减少障碍物）

**Python 示例**:
```python
import requests

def plan_trajectory(start, goal):
    response = requests.post(
        "http://localhost:8000/plan",
        json={"start": start, "goal": goal}
    )
    return response.json()

# 使用
result = plan_trajectory(
    {"x": 0, "y": 0, "z": 1},
    {"x": 10, "y": 5, "z": 1.5}
)
```

**JavaScript 示例**:
```javascript
async function planTrajectory(start, goal) {
  const response = await fetch('http://localhost:8000/plan', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({start, goal})
  });
  return await response.json();
}

// 使用
const result = await planTrajectory(
  {x: 0, y: 0, z: 1},
  {x: 10, y: 5, z: 1.5}
);
```
